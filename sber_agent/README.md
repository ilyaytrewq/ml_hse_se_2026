# Сбер PR-агент

Собирает упоминания Сбера из RSS Retail.ru, Sostav и AdIndex без Google News.
GigaChat оценивает тональность и срочность; агент сохраняет CSV и отправляет
в Telegram дайджест с тональностью по каждому RSS. Для PR-команды Сбера.

## Запуск
1. Откройте `Copy_of_П5_Агент.ipynb` в Google Colab.
2. В конфигурации явно задайте `gigachat_creds`, `TELEGRAM_BOT_TOKEN`
   и `TELEGRAM_CHAT_ID`. Перед полным запуском проверьте повторные конфиги рядом.
3. Напишите `/start` своему боту, затем выполните все ячейки по порядку.
4. Сохраните CSV и сделайте скриншот дайджеста с ником бота.

Бренд, ключевые слова, RSS и лимит статей задаются в `AGENT_CONFIG` в шаге 0.
RSS содержит только доступные свежие записи: упоминаний может не оказаться.
Для сдачи нужны выполненная тетрадка, этот README и скриншот ответа бота.
